Q-Learning Reinforcement Learning Lab

📌 Overview

This repository contains a practical implementation of the Q-Learning algorithm, one of the foundational techniques in Reinforcement Learning (RL).
The project demonstrates how an intelligent agent can learn optimal actions through interaction with an environment using rewards and penalties.

The objective of this lab is to understand:

Reinforcement Learning fundamentals
The Q-Learning update mechanism
Exploration vs Exploitation
Policy optimization through iterative learning
How agents learn from experience without supervised labels

This project is part of an academic and practical exploration of Artificial Intelligence and Machine Learning concepts.
